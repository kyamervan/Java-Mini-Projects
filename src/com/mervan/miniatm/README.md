# Mini ATM Simulation 🏦

[English]
A console-based ATM simulation designed to practice core Java control flow, loops, and state management. This project demonstrates fundamental modular programming by separating banking operations into distinct methods.

**Note:** The source code variable names and console outputs are currently in **Turkish** for educational purposes.

## 🚀 Features
* **Authentication:** 4-digit PIN verification with a 3-attempt limit.
* **Banking Operations:** View balance, deposit money, and withdraw funds.
* **Security Checks:** Prevention of negative amount inputs and insufficient balance handling.
* **Modular Design:** Clean code architecture using separate Java methods.

---

[Türkçe]
Java kontrol akışını, döngüleri ve durum yönetimini (state management) pratik etmek için tasarlanmış konsol tabanlı bir ATM simülasyonu. Bu proje, bankacılık işlemlerini farklı metotlara ayırarak temel modüler programlama mantığını gösterir.

## 🚀 Özellikler
* **Kimlik Doğrulama:** 3 giriş haklı, 4 haneli PIN doğrulama sistemi.
* **Banka İşlemleri:** Bakiye görüntüleme, para yatırma ve para çekme.
* **Güvenlik Kontrolleri:** Negatif tutar girişini (- TL) ve yetersiz bakiye işlemlerini engelleme.
* **Modüler Yapı:** Temiz kod mimarisi için işlemlerin ayrı metotlara bölünmesi.

## 🛠 Kurulum / Installation
1.  Clone the repository / Projeyi indirin.
2.  Open in IntelliJ IDEA or Eclipse / IDE ile açın.
3.  Run `AtmApp.java` / `AtmApp.java` dosyasını çalıştırın.
4.  **Default PIN / Varsayılan Şifre:** `1532`
