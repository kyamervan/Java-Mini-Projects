# Java Logic Toolkit ☕

[English]
A console-based utility toolkit designed to practice core Java logic, algorithms, and data structures. This project demonstrates fundamental logic building blocks using Strings, Numbers, and Arrays without relying on external libraries.

**Note:** The source code variable names and console outputs are currently in **Turkish** for educational purposes.

## 🚀 Features
* **String Operations:** Case conversion, reverse string logic, pattern matching.
* **Number Operations:** Even/Odd check, Positive/Negative check, Digit summation logic.
* **Array Operations:** Finding max value, calculating average, sequence detection (1-2-3).

[Türkçe]
Java mantık yapısını, algoritmaları ve veri yapılarını pratik etmek için tasarlanmış konsol tabanlı bir araç seti. Bu proje; String, Sayı ve Dizi işlemlerini harici kütüphane kullanmadan, temel mantık bloklarıyla gösterir.

## 🚀 Özellikler
* **String İşlemleri:** Harf büyütme, ters çevirme, metin içi desen arama.
* **Sayı İşlemleri:** Tek/Çift kontrolü, Pozitif/Negatif kontrolü, Basamak toplama.
* **Dizi İşlemleri:** En büyük sayıyı bulma, ortalama hesaplama, sıralı dizi kontrolü.

2.  Open in IntelliJ IDEA or Eclipse / IDE ile açın.
